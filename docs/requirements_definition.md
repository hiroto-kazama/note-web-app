# プロジェクト要件定義書

**プロジェクト名**: Simple Note Web App  
**目的**: ユーザー認証とノートのCRUD機能を備えたシンプルかつ完成度の高いWebアプリケーションの開発（学習目的）  
**作成日**: 2026-07-21  
**ステータス**: 要件定義完了  

---

## 1. プロジェクト概要・目的

### 1.1 背景・目的
複雑な階層管理やシェア機能は削ぎ落とし、**「ユーザーログイン」から「ノートの作成・編集・削除（CRUD）」** に特化したシンプルな構成にする。  
認証フロー、状態管理、UIコンポーネント化、ローカル永続化（またはAPI連携）などのWeb開発の基礎〜実践スキルをしっかりと学習・習得することを目的とする。

---

## 2. システムモデル・データ構造

データモデルはシンプルな 1:N 関係とする。

```
[ ユーザー (User) ]
       │
       └── (1 : N) ──> [ ノート (Note) ]
```

### 2.1 ノートオブジェクトの基本構造 (案)
- `id`: ノートの固有識別子 (UUID / タイムスタンプ)
- `userId`: 所有するユーザーのID
- `title`: ノートのタイトル
- `content`: ノートの本文
- `createdAt`: 作成日時
- `updatedAt`: 最終更新日時

---

## 3. 機能要件 (Functional Requirements)

### 3.1 認証機能 (Authentication)
- [ ] **ユーザー登録 / サインアップ**: アカウントの新規作成
- [ ] **ログイン / ログアウト**: ログイン状態の保持とセッション管理
- [ ] **認証ガード**: 未ログイン状態ではノート一覧・編集画面にアクセスできない制御

### 3.2 ノート管理機能 (Note CRUD)
- [ ] **ノート一覧表示**: ログイン中のユーザーが所有するノートの一覧（作成・更新順）
- [ ] **ノート作成**: 新規ノートの追加
- [ ] **ノート編集**: 既存ノートのタイトル・本文のリアルタイム/手動編集
- [ ] **ノート削除**: 不要なノートの削除（確認ダイアログ付き）
- [ ] **キーワード検索**: タイトルまたは本文のリアルタイムフィルタリング検索

---

## 4. スコープ外 (非対象機能)
学習のステップを明確にするため、以下の機能は今回の初期バージョンでは**実装しない**。
- 3層構造（ノートブック / セクション / ページなどの複雑な階層分類）
- 他人とのノート共有・リアルタイム共同編集機能
- 複雑なリッチテキスト装飾（標準的なテキスト/簡単なMarkdownに留める）

---

## 5. 技術スタック・アーキテクチャ (フルスタック自作構成)

既存のBaaS（Firebase等）を使わず、バックエンドAPIやデータベース、認証の仕組みを自作・構築して仕組みを深く学ぶ。

- **フロントエンド**:
  - HTML5, Vanilla CSS, Vanilla JavaScript (ES6+)
  - 非同期通信: `Fetch API` (`async` / `await`)
- **バックエンドサーバー**:
  - **言語・環境**: Node.js (Express)
  - **役割**: RESTful APIの提供、認証処理、CORS制御、MySQL操作 (`mysql2` ドライバ/コネクションプール)
- **データベース**:
  - **MySQL**: 本格的なリレーショナルデータベース (テーブル設計、外部キー制約、インデックス活用)
- **認証・セキュリティ**:
  - パスワードハッシュ化 (`bcrypt`)
  - 認証方式: JWT (JSON Web Token)

---

## 6. API設計概要 (RESTful API 案)

### 6.1 認証系エンドポイント
- `POST /api/auth/register` : ユーザー新規登録
- `POST /api/auth/login` : ログイン (トークン / セッション発行)
- `POST /api/auth/logout` : ログアウト
- `GET /api/auth/me` : ログイン中ユーザー情報の取得 (認証チェック)

### 6.2 ノート操作系エンドポイント (要認証)
- `GET /api/notes` : ノート一覧取得
- `POST /api/notes` : ノート新規作成
- `GET /api/notes/:id` : ノート詳細取得
- `PUT /api/notes/:id` : ノート更新
- `DELETE /api/notes/:id` : ノート削除
